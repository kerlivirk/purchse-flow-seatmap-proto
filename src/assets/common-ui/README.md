# @piletilevi/common-ui-assets

This library is a collection of PLG moments common ui assets

## Versioning
To update the client version, please modify the package.json [`version`](https://github.com/Piletilevi/common-ui-assets/blob/main/package.json#L3) field accordingly.

## Building
To make a npm pack for local development:
```console
npm install
npm pack
```
Use it in the project as:
```console
npm install ../common-ui-assets/common-ui-assets-x.z.y.tgz
```
