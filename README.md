# Interactive Event Ticketing Prototype

Updated prototype with a black/grey/purple visual system and a coherent interactive ticketing map flow.

## What changed

- Reworked main app theme to dark black / grey / purple.
- Added a reservation timer that starts only after the first successful seat or GA pre-reservation.
- Rebuilt the venue map as one coherent interactive component.
- Added venue overview mode with sections and price badges.
- Added pure full-venue map mode without ticket overlays.
- Added sector drill-down to individual seats.
- Added zoom, pan, minimap, filters, legend, access code, search panel, GA purchase, best available seats, table purchase, pre-reservation loading, failed reservation, selected seats, reserved-by-other seats, limited-view notes, accessible seat markers, and multi-category price selection.
- Updated header and ticket type visuals to match the dark palette.

## Prototype access code examples

Use one of these in the access-code field:

- CREW
- PRESS
- PHANTOM
